# Chrome 扩展商店

## 商店地址

https://chromewebstore.google.com/detail/anobmlnjdeahldefeikjdmmnckphpdhc

## 名称与简介

名称：dsh-chrome-use

简介：操纵你正在使用的 Chrome：新建或复用已登录标签页，读取页面、点击、填写、拖拽、滚动、截图，查看控制台与网络日志。多个 Agent 会话可同时操作不同标签页，同一标签页自动排队。商店安装，8 位配对码连接，自动选择可用端口。

## 详细介绍

操纵你正在使用的 Chrome 浏览器：新建或复用已登录的标签页，让模型读取页面、点击、填写、拖拽页面元素、滚动、截图，新建标签页并分组、关闭本会话打开的标签页，查看控制台与网络日志、按需读取单条响应体、查看下载记录，调试浏览器等。多个 Agent 会话可以同时操作不同的标签页，同一标签页会排队执行。扩展从 Chrome 应用商店安装，用 8 位配对码连接；配对码可能含字母，并包含实际端口。

它把 Chrome 接到本机 DeepSeek Harness，不用复制链接，也不用重复登录；首次配对后保存连接凭据，后续自动重连。

能做什么

• 点击、双击、右键、悬停、拖拽页面元素、下拉选择
• 填写表单，按 Enter、Tab、Esc、Home、End、PageUp、PageDown，以及 meta+a、ctrl+shift+k 等组合键
• 一次上传一个或多个文件
• 等待元素出现、文字出现、网址变化或网络空闲
• 刷新、后退、前进，把标签页切到前台
• 新建标签页并放进同名标签页组；关闭本会话打开的标签页
• 滚动到指定元素，也支持内部滚动容器
• 截取视口、整页或单个元素
• 把页面导出为 PDF
• 处理 alert、confirm、prompt 对话框
• 读取页面结构、控制台、JavaScript 错误和网络状态
• 操作开放 Shadow DOM 内的元素

并发与协调

• 多个 Harness 会话（Agent）可以同时操作不同的标签页，读取、等待和截图互不阻塞
• 多个 Harness 进程可以用不同端口同时连接；每个进程独立配对，标签页占用由扩展统一协调
• 同一 Harness 内，同一标签页同一时间只执行一条命令；其他会话申请时按先来后到排队，最多等 10 秒
• 不同 Harness 之间不排队：标签页已被另一个 Harness 占用时立即返回 `TAB_OWNED_BY_ANOTHER_HARNESS`
• 点击、输入、拖拽、关闭、激活等会切换前台的操作自动排队，避免中途抢走焦点
• 取消或超时后，等扩展确认清理完成才释放占用；超过 8 秒仍未清理会断开连接，避免旧操作影响下一个会话
• 这些锁只协调本插件发出的操作，不能阻止你手动切换页面、其他扩展或网页脚本改变焦点

首次配对后保存连接凭据，后续自动重连。连接后，AI 可以选择所有普通 HTTP(S) 标签页，不需要逐页授权。

调试时 Chrome 会显示调试提示，点击时页面会短暂显示蓝色箭头。扩展弹窗列出每个端口的连接状态，可单独连接或忘记，也可以随时断开全部连接。

使用前

需要在同一台电脑安装 DeepSeek Harness 和本仓库提供的 Harness 插件。扩展不提供模型服务，不包含模型 API Key。你选择的模型服务可能处理工具返回的网页内容。

## 单一用途

为用户配置的本机 DeepSeek Harness 提供 Chrome 页面操作和调试能力。

## 权限用途

| 权限 | 用途 |
|---|---|
| `debugger` | 读取页面结构，执行浏览器输入、截图和网页调试 |
| `tabs` | 列出和选择标签页，读取目标页标题及 URL |
| `tabGroups` | 把 chrome_open 打开的标签页放进同名标签页组 |
| `storage` | 保存配对令牌和自动重连状态 |
| `alarms` | 在 Harness 重启或连接中断后尝试重连 |
| `downloads` | 按用户要求列出下载记录，确认文件是否保存成功；不修改下载内容 |

## 数据披露依据

以仓库 [PRIVACY.md](../PRIVACY.md) 为准。作者没有页面数据接收服务器。工具结果会进入用户的 Harness 会话，并可能发送给用户选择的模型提供方。截图和配对数据保存在本机。

调试工具可按用户要求在页面执行 JavaScript。商店的代码执行及数据披露问卷需要与上述内容保持一致，审核政策变化时同步复核。

## 上架状态

扩展已在 Chrome 应用商店公开，用户可以直接从上面的商店地址安装，并由 Chrome 自动更新。

仓库发布不会改变商店版本：仓库里的扩展版本更新后，需要把新的扩展包重新上传到商店，审核通过后用户才会收到更新。0.6.0 增加多会话并发，扩展包和本页描述要一起更新。没有准备 Edge 商店版本。
