dsh-chrome-use

让本机的 DeepSeek Harness 用你自己的 Chrome 读取页面、点击、输入、截图和导出 PDF。

隐私说明 支持与反馈 源码仓库

它做什么

  • 复用你已经登录的标签页，不需要重新登录，也不需要输入网址。
  • 读取页面正文或近似 Markdown、查找元素、点击、输入、悬停、拖拽、上传文件。
  • 截图、导出 PDF、查看控制台信息、网络请求和下载记录。
  • 多个会话可以并行操作不同标签页；同一个标签页按先后顺序排队。

怎么用

  • 在 Chrome 应用商店安装本扩展。
  • 在本机安装 DeepSeek Harness 插件：npm install -g dsh-chrome-use，或用 Harness 的插件管理安装。
  • 打开扩展弹窗，输入 Harness 给出的一次性配对码，之后即可在会话中使用 chrome_* 工具。

权限与数据

扩展需要 debugger、tabs、tabGroups、storage、alarms 和 downloads 权限，分别用于通过 DevTools 协议操作页面、选择标签页、整理标签组、保存配对状态、恢复连接和读取下载记录。扩展只连接本机 127.0.0.1:18791，不向作者的服务器发送任何数据。详见隐私说明。

English: dsh-chrome-use is a Chrome extension that lets your local DeepSeek Harness plugin read and drive Chrome tabs you already have open. It talks only to 127.0.0.1:18791 and sends nothing to the author's servers. See the privacy policy.
