# Chrome 扩展商店材料草稿

## 名称与简介

名称：dsh-chrome-use

简介：让本机 DeepSeek Harness 读取、操作和调试 Chrome 网页。

## 详细介绍

dsh-chrome-use 将 Google Chrome 连接到本机 DeepSeek Harness。首次配对后保存连接凭据，后续自动重连。连接后，AI 可以选择普通网页，执行点击、输入、滚动和导航，也可以读取页面结构、保存截图、查看控制台及网页错误。

调试时 Chrome 会显示调试提示。扩展弹窗提供连接状态和断开按钮，无需逐页授权。你可以随时断开全部操作。

使用前需要在同一台电脑安装 DeepSeek Harness 和本仓库提供的 Harness 插件。扩展不提供模型服务，不包含模型 API Key。你选择的模型服务可能处理工具返回的网页内容。

## 单一用途

为用户配置的本机 DeepSeek Harness 提供 Chrome 页面操作和调试能力。

## 权限用途

| 权限 | 用途 |
|---|---|
| `debugger` | 读取页面结构，执行浏览器输入、截图和网页调试 |
| `tabs` | 列出和选择标签页，读取目标页标题及 URL |
| `storage` | 保存配对令牌和自动重连状态 |
| `alarms` | 在 Harness 重启或连接中断后尝试重连 |

## 数据披露依据

以仓库 [PRIVACY.md](../PRIVACY.md) 为准。作者没有页面数据接收服务器。工具结果会进入用户的 Harness 会话，并可能发送给用户选择的模型提供方。截图和配对数据保存在本机。

调试工具可按用户要求在页面执行 JavaScript。正式提交前需要在商店的代码执行及数据披露问卷中如实说明，并根据当时的审核政策核对提交方式。
